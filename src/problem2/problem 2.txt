Build a currency swap form in React using Vite.
The form should let users choose two currencies (from and to), enter an amount, and see the converted result.
Use React state, a token price mock API, and show exchange rate dynamically.
Implement dropdowns to select tokens, and input for amount.
Add a Swap button with loading indicator (simulate delay 1.5s).
Skip actual backend, just simulate conversion logic using exchange rates.
Add basic input validation (disable button if amount ≤ 0 or tokens are the same).
Use TailwindCSS for UI.
Include placeholder token icons and mock price data inside src/data/tokens.ts.
Make the layout mobile responsive and user-friendly.
Folder structure should follow src/components, src/hooks, src/data, etc.
Bonus: use Vite to initialize the project.
